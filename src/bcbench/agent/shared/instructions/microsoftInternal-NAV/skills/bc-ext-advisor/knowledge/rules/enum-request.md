# Enum Request Rules

Apply to `enum-request`, in addition to the general rules.

## Implementation guidance
- **Declare `Extensible = true`.** *Apply directly* for every new enum.
- **Space ordinals.** *Apply directly.* Leave gaps (0, 10, 20, …) for future insertions.
- **Caption every value.** *Apply directly.* Each value needs a user-readable `Caption`.
